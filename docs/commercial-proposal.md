# Коммерческое предложение

## Проект: AIbank — IT-платформа для онбординга и обслуживания МСБ/корпоративных клиентов

## Цель

Построить полноценную IT-платформу банка для МСБ и корпоративных клиентов:
онбординг юридических лиц, личный кабинет (web), back-office портал для
сотрудников банка, AML/комплаенс-модуль, аналитика и безопасность
по банковским стандартам РФ. Целевой горизонт — **5-20 тыс. активных
юрлиц за 2 года**.

---

## Объём первой версии

### 1. Онбординг юрлица (10-этапный wizard) — **₽8-12 млн**

- Двухфазная регистрация applicant'а (email+password или phone+OTP)
- Этап 1: предварительный скоринг по ИНН/ОГРН (ЕГРЮЛ, Росфинмон, ФССП, ЗСК ЦБ)
- Этап 2: расширенная анкета юрлица (ОПФ, 3 структурированных адреса, ОКВЭД, лицензии, СРО, контакты, финансовые показатели)
- Этап 3: AML-сведения (контрагенты top-5, операционная модель, ВЭД, источник средств)
- Этап 4: ЕИО и представители (паспортные данные, полномочия, ПДЛ-декларация)
- Этап 5: Бенефициарные владельцы (УБО) + FATCA/CRS
- Этап 6: загрузка документов (typed list: устав, лист записи ЕГРЮЛ, протокол ЕИО, лицензии, отчётность) с drag-and-drop, PDF preview, УКЭП-подписанием
- Этап 7: AML-проверки (sanctions screening — OFAC SDN / EU CFSP / UK HMT / СДН РФ, PEP screening, adverse media, anti-fraud сигналы)
- Этап 8: автоматический риск-скоринг (CatBoost + SHAP-объяснимость + transaction limits)
- Этап 9: открытие счёта (account_type, тариф, согласия — ДБО / ЭДО / ПДн, signing-method)
- Бизнес-правило «один applicant = одна заявка», workflow на Apache Temporal

### 2. Личный кабинет клиента (web SPA + PWA) — **₽5-7 млн**

- Список и история заявок
- Детальная страница заявки с roadmap из 8 шагов прохождения
- Уведомления о смене статуса (in-app + email)
- Загрузка дополнительных документов после комментариев банка
- AI-чат-бот для типовых вопросов (rag-service: 115-ФЗ, 375-П, 639-П, тарифы)
- Per-tenant брендирование (logo, цвета, шрифты по theme.json)
- Mobile-friendly PWA (нативное iOS/Android — отдельным проектом)

### 3. Back-office портал банка (web-admin) — **₽5-7 млн**

- Список заявок с фильтрами (статус, юр. форма, ИНН, дата)
- Детальная страница заявки с агрегированными данными по всем 10 этапам
- Модуль ручной модерации с обязательным комментарием 20+ символов
- Просмотр audit-trail (append-only с криптографической подписью SHA-256 hash chain)
- Управление tenant-config'ом (тарифы, риск-пороги, ОКВЭД-блокировки)
- Compliance dashboard: воронка заявок, KYC-расхождения, sanctions hits
- RBAC: роли bank.operator, bank.compliance_officer, bank.admin, platform.admin

### 4. AML / комплаенс-модуль — **₽7-11 млн**

- Реальная интеграция с ФНС ЕГРЮЛ (через СМЭВ-3, договор Минцифры)
- Интеграция с Росфинмониторингом (115-ФЗ XML фид, ежесуточный cron)
- Интеграция с ФССП (исполнительные производства, IS-канал, mTLS)
- Интеграция с ЗСК ЦБ (Знай Своего Клиента — светофор)
- Интеграция с СПАРК / Контур.Фокус (per-tenant)
- ЕСИА для бизнеса (OIDC relying party)
- CatBoost-модель риск-скоринга (обучение на синтетике + 100-300 кейсов банка) с ONNX export и SHAP-объяснимостью
- Periodic KYC review каждые 3/6/12 мес по 375-П
- Право на удаление по 152-ФЗ ст. 14 (real delete + audit-log retention 5 лет)

### 5. Аналитика и отчётность — **₽2-4 млн**

- BI-дашборды для бизнеса банка: воронка онбординга, сроки решений, отказы по причинам, риск-категории, объёмы
- Compliance-отчётность для регулятора (115-ФЗ, 375-П, 639-П)
- Audit-log просмотрщик с поиском и экспортом
- Exports в CSV / XLSX / JSON для BI-инструментов банка (Power BI, ClickHouse)
- Метрики платформы: VictoriaMetrics + Grafana + Loki + Tempo

### 6. Безопасность и compliance по стандартам РФ — **₽5-9 млн**

- 152-ФЗ УЗ-2 аттестат (через лицензированного аудитора, сертификат)
- СКЗИ КриптоПро / VipNet (ГОСТ-2012 подписи) для УКЭП-документов
- Vault HA cluster с auto-unseal и AppRole flow
- Vault Transit для field-level encryption PII (паспорт, СНИЛС, ИНН)
- mTLS между сервисами через Istio sidecar (SPIFFE-identity)
- TLS 1.3 + cert-manager (Let's Encrypt для SaaS, internal CA для on-prem)
- WAF (Cloudflare для SaaS) + per-tenant rate limit
- Pen-test внешним подрядчиком (раунд 1) + аудит-bundle для ИБ
- Audit log с криптографической подписью каждой записи (Ed25519 / ГОСТ-2012)
- 24h уведомление в РКН при инциденте (runbook + автоматизация)

### 7. Инфраструктура и DevOps — **₽3-5 млн**

- Kubernetes 1.30+ кластер (Yandex Cloud / VK Cloud для SaaS, on-prem — Ansible-разворот)
- Terraform для cloud-провайдеров + Helm-чарты per-сервис
- Managed PostgreSQL 16 (per-tenant schema-isolation, ADR-0002)
- Kafka KRaft cluster (без ZooKeeper, tiered storage, encryption at rest)
- MinIO distributed mode для object storage
- GPU pool (1× A100 80GB на пилот, 2× A100 / H100 на production) для vLLM
- CI/CD pipeline (GitHub Actions): автоматические тесты, golangci-lint, eslint, spectral, build, deploy
- Backup & DR: PostgreSQL WAL archive + offsite snapshots, RTO ≤ 4ч / RPO ≤ 15 мин

---

## Итого

**Оценка проекта: ₽35-55 млн**
**Срок реализации: 28-40 недель (7-10 месяцев)**

При наличии готового pre-MVP skeleton (текущее состояние AIbank: 21 Go-сервис + 6 AI-агентов + 2 фронтенда — ~55 000 строк кода) объём «с нуля» сокращён примерно вдвое — отсюда диапазон.

## Допущения

- Оценка дана на основании текущего описания задачи и состояния pre-MVP
  репозитория AIbank на 2026-05-08.
- Финальная стоимость может измениться после уточнения требований
  (тип АБС банка, регуляторный профиль — топ-200 КИИ или нет, on-prem
  / SaaS, объёмы заявок, set интеграций).
- Клиент-банк предоставляет: доступы к АБС, тестовый ИНН-набор для
  обучения CatBoost, бренд-материалы (logo, фирстиль), доменное имя,
  TLS-сертификаты, договорённости с ФНС/Росфинмон через свой
  юридический отдел.
- Изменения сверх согласованного объёма оцениваются отдельно через
  change-request процедуру.
- Параллельная работа: backend + frontend + DevOps идут одновременно
  командой 4-5 senior-инженеров.
- Регуляторика (УЗ-2 аттестат, СКЗИ-лицензии) имеет жёсткий lead-time
  6-9 месяцев, который начинает идти параллельно с разработкой.

## Не входит

- Нативные мобильные приложения iOS/Android (только PWA)
- ABS-адаптеры для Diasoft FA# и RS-Bank/ЦАБС (только ЦФТ для первого
  банка; другие — отдельным проектом)
- Поддержка после запуска (отдельный maintenance-контракт ₽300-700K/мес)
- Продвижение и реклама онбординг-кабинета
- Покупка домена, хостинга, платных API
  (СПАРК/Контур.Фокус, GPU-провайдеров)
- Написание контента: тексты согласий, FAQ, оferty, пользовательских
  инструкций (предоставляет банк-клиент или маркетинговое агентство)
- ISO 27001 сертификация (отдельным проектом, 12-18 мес, ~₽3-7M)
- Multi-region failover для географически распределённого банка
- Marketplace плагинов и third-party интеграций
- Сложные кастомные интеграции, не описанные заранее: BPM-системы
  банка, специализированные CRM, проприетарные риск-движки

## Следующий шаг

1. **Discovery-сессия** (3-5 рабочих дней): уточнение типа АБС банка,
   состава внешних интеграций, регуляторного профиля, объёмов трафика,
   деплой-модели (SaaS vs on-prem).
2. **Подготовка детального ТЗ** (2-3 недели): функциональные требования,
   ER-модель, OpenAPI-контракты, дизайн-макеты ключевых экранов,
   non-functional requirements (SLA, RPO/RTO, объёмы, пиковая нагрузка).
3. **Утверждение MVP-объёма и контракта** (включая пилот на 1-2 банка
   с оценочной длительностью 6-12 недель shadow-mode).
4. **Запуск проекта** с регулярными sprint review (2 недели цикл) +
   monthly steering committee с ИТ-руководством банка.
