# Внутренняя смета AIbank — до первого пилотного банка

Документ отвечает на вопрос: **«Сколько денег нужно, чтобы дойти от
текущего pre-MVP staging до первого реального банка-партнёра в проде?».**

Не включает: revenue, post-pilot scaling, mobile-app, ISO 27001 (year 2).
Источники: [docs/pilot-readiness.md](pilot-readiness.md),
[docs/deployment/server-sizing.md](deployment/server-sizing.md),
[docs/onboarding-form-spec.md](onboarding-form-spec.md), git log.

Все суммы в **рублях, gross** (с налогами и страховыми, ставки senior
по рынку Москва/удалёнка 2026 Q2).

---

## TL;DR

| Сценарий | Срок до пилота | Команда | ИТОГО |
|----------|----------------|---------|-------|
| **Lean** (минимум для MVP) | 9 месяцев | 3 senior + контрактники | **₽13-16M** |
| **Standard** (рекомендуемый) | 7 месяцев | 4 senior full-time + part-time security | **₽17-22M** |
| **Fast** (если есть капитал) | 5 месяцев | 5 senior + QA + дизайнер | **₽23-28M** |

Все сценарии включают резерв 15%. Главный риск — регуляторика (УЗ-2)
имеет жёсткий lead-time 6-9 месяцев, поэтому Fast-сценарий сжимает не
больше чем до 5 месяцев — раньше аттестат не выдадут.

## Что можно сэкономить (опции)

| Сокращение | Эффект | Риск |
|------------|--------|------|
| УЗ-2 после первого LOI (а не до) | -₽3M в M0-M6 | Банк не подпишет контракт без аттестата → блокер |
| Без ESIA в пилоте (только email-логин applicant'а) | -₽300-500K разработка | UX хуже, но допустимо для pilot |
| Без bge-m3 reranker'а (Jaccard placeholder) | -2-3 нед разработки | Качество RAG ниже на 10-15%, не критично |
| Без Diasoft/RS-Bank адаптеров (только ЦФТ для первого банка) | -3 нед | Привязка к конкретному ABS — допустимо для 1-го пилота |
| Без mobile PWA branding | -1-2 нед UX | Браузер достаточен, ADR разрешает |

Минимально-достаточный сценарий: **₽12-14M** (Lean минус УЗ-2-pre-pilot, плюс LOI до старта).
