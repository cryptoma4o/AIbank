# configs/

Конфигурации тенантов (банков-клиентов платформы).

См. [docs/tenant-configuration.md](../docs/tenant-configuration.md) для полной спецификации.

## Структура

```
configs/
├── tenants/
│   ├── _template/    # шаблон конфигурации нового банка (см. ниже)
│   ├── demo-bank/    # демо-тенант для продаж и тестов
│   └── ...           # реальные банки — добавляются по мере подключения
└── schemas/          # JSON Schema для валидации конфигов
```

## Принципы

- Конфигурация — это код, версионируется в Git
- Применение — через GitOps (ArgoCD), не вручную
- Изменения проходят валидацию по JSON Schema + бизнес-правилам
- Секреты — только ссылки на Vault, никаких реальных значений
