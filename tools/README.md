# tools/

Внутренние тулы: моки, генераторы, CLI.

См. [docs/technical-structure.md](../docs/technical-structure.md), раздел 2.

## Планируемые тулы

- `mock-abs-cft/` — мок ЦФТ для разработки и тестов без реального банковского АБС
- `mock-abs-diasoft/` — мок Diasoft FA#
- `tenant-cli/` — CLI для управления тенантами (создание, валидация, применение)
- `data-generator/` — генератор синтетических кейсов для eval-корпусов

## Принципы

- Mock-сервисы реализуют те же API, что и реальные системы
- Mock-данные генерируются детерминированно (фиксированный seed для воспроизводимости)
- CLI следуют принципу UNIX (одна задача — одна команда)
