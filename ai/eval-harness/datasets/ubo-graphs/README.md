# ubo-graphs eval corpus

Синтетический корпус для оценки качества прослеживания цепочек владения (UBO —
Ultimate Beneficial Owner). Используется агентом `agent-ubo-tracing`.

## Состав v1

| Файл | Кейсы | Тип | Цель |
|---|---|---|---|
| `ubo-cases.json` | 20 | Граф владения | Извлечение узлов/рёбер, UBO, нерезолвящихся веток |

Подсеты:

- 5 кейсов **trivial** — 1 учредитель-физлицо со 100% долей → 1 UBO
- 5 кейсов **split** — 2-3 учредителя, доли 33-50%; каждый ≥25% становится UBO
- 5 кейсов **nested** — ООО владеет ООО, которым владеет физлицо; эффективная доля = произведение
- 5 кейсов **edge** — иностранный филиал (`unresolved_branches`), госучастие, мелкий технический владелец <25%, анонимный траст

## Метрики

Скоринг кейса состоит из трёх компонентов:

```
score = 0.4 * graph_iou(nodes, edges)
      + 0.4 * ubo_set_iou(expected_ubos, actual_ubos)
      + 0.2 * unresolved_match
```

Кейс считается `pass` при score ≥ 0.8.

## Источник данных

Все кейсы **синтетические**. ИНН физлиц и юрлиц сгенерированы с корректными
контрольными разрядами (12-значный для физлиц, 10-значный для юрлиц).
Имена компаний — выдуманные (Ромашка, Берёзка и т.п.). Иностранные юрисдикции —
плейсхолдеры `Cyprus Holdings Ltd.`, `BVI Trust Inc.` без отсылок к реальным фирмам.

## Owner

ML-инженер + банковский эксперт по AML (ADR-0012, см. `docs/technical-structure.md` § 7.5).
До назначения owner'а корпус считается v0.

## Запуск

```bash
cd ai/eval-harness
python -m harness.cli run datasets/ubo-graphs/ubo-cases.json --agent-url http://localhost:8106
```

Перегенерация:

```bash
cd ai/eval-harness/datasets/ubo-graphs
python3 _generate.py
```

## Расширение

Новые кейсы добавляются через PR с пометкой `eval-corpus`. Изменение существующих
кейсов запрещено без обоснования. Нумерация — последовательная по подсетам
(`ubo-graphs-trivial-006`, `ubo-graphs-split-006`, `ubo-graphs-nested-006`,
`ubo-graphs-edge-006`).
